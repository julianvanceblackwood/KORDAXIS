# First Synthetic Range — GEN0-001

## Purpose
GEN0-001 is a controlled vertical slice for evaluating reconstruction under incomplete observability. Ground truth is generated by the range and withheld from KORDAXIS inference components.

## Environment

- one employee identity
- one Git provider organization
- one repository
- one CI workflow
- one CI runner identity
- one cloud federation binding
- one deployment role
- one artifact registry
- one workload identity
- one production workload
- one database
- one mission capability
- three telemetry producers with distinct failure domains

## Ground-truth sequence

T0 normal environment.

T1 employee session becomes unauthorized.

T2 repository reconnaissance occurs.

T3 CI trust relationship is discovered.

T4 an authorized software/build path changes.

T5 CI workflow executes.

T6 short-lived cloud authority is obtained through federation.

T7 build/artifact lineage diverges from expected policy.

T8 artifact enters deployment path.

T9 production workload authority becomes reachable.

T10 database becomes reachable.

T11 Mission Capability Alpha becomes at risk.

## Observability impairment

Between T4 and T7, one telemetry producer loses a defined subset of observations.

Controlled variants later include event loss, delivery delay, clock skew, duplicates, false-positive injection, sensor outage, stale context, and conflicting assertions.

## Competing hypotheses

H1 — compromised employee session caused the suspicious software-path changes.

H2 — legitimate emergency administration explains the changes.

H3 — the human identity remained legitimate and a CI/supply-chain component explains the anomaly.

H4 — part of the apparent incident results from degraded telemetry and inconsistent clocks.

KORDAXIS must preserve plausible alternatives until evidence distinguishes them.

## Isolation rule
The range uses synthetic identities, synthetic resources, and isolated data. No real external target is part of Generation-0 evaluation.
